Problem: 344. Reverse String (C#)
Status: Accepted

Solution Code (Two Pointers):
public class Solution {
    public void ReverseString(char[] s) {
        int left = 0;
        int right = s.Length - 1;
        
        while (left < right) {
            char temp = s[left];
            s[left] = s[right];
            s[right] = temp;
            
            left++;
            right--;
        }
    }
}

Time Complexity: O(N)
Space Complexity: O(1)
